Add Friend / Remove Friend

About the Project

This is a simple JavaScript project that demonstrates how to use JavaScript DOM manipulation and event listeners to create an interactive Add Friend / Remove Friend button.

When the user clicks the button, the status changes between "Friends" and "Strange".

Features

Add Friend functionality.

Remove Friend functionality.

Dynamic text updates.

Text color changes based on friendship status.

Interactive button using JavaScript.

Technologies Used

HTML5

CSS3

JavaScript

How It Works

Initially, the counter value is 0.

When the user clicks the Add Friend button:

Text changes to "Friends".

Text color changes to green.

Button text changes to "Remove".

When the user clicks the Remove button:

Text changes to "Strange".

Text color changes to red.

Button text changes to "Add Friend".
